## 🎨 Design System Quick Reference

### Colors
```css
--pitch-black: #111111      /* Borders, text */
--pure-white: #ffffff       /* Card backgrounds */
--off-white: #fdfdfd        /* Page backgrounds */
--neon-yellow: #ccff00      /* Primary actions */
--electric-purple: #9B30E0  /* Secondary accents */
--action-pink: #ff3366      /* Destructive/like actions */
```

### Typography
- **Headlines**: Bebas Neue, uppercase, tight leading
- **Body**: Space Grotesk, medium-bold weights
- **Labels**: Space Grotesk, bold, uppercase, tracking-wider

### Shadows
- **Small**: `4px 4px 0px #111`
- **Medium**: `6px 6px 0px #111`
- **Large**: `8px 8px 0px #111` to `12px 12px 0px #111`
- **Hero**: `7px 7px 0px` or `8px 8px 0px`

### Borders
- **Standard**: `2px solid #111`
- **Emphasis**: `3px solid #111`
- **Hero**: `4px solid #111`

### Hover Pattern
```jsx
onMouseEnter={(e) => {
  e.currentTarget.style.transform = 'translate(2px, 2px)';
  e.currentTarget.style.boxShadow = '4px 4px 0px var(--pitch-black)';
}}
onMouseLeave={(e) => {
  e.currentTarget.style.transform = 'translate(0, 0)';
  e.currentTarget.style.boxShadow = '6px 6px 0px var(--pitch-black)';
}}
```
